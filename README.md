# Chaos-Control
Таск-менеджер — мобильное приложение для личного и командного планирования задач. Оно собирает в одном месте личные дела и задачи команды, помогает не пропускать дедлайны и показывает ход работы с помощью канбан-доски и диаграммы Ганта.

# О проекте
 
**Проблема.** В повседневной жизни дела часто разбросаны по разным местам — заметкам, мессенджерам, памяти — из-за чего возникает хаос: задачи теряются, дедлайны срываются, а часть дел забывается просто потому, что для них нет единой системы учёта.
 
**Цель.** Разработать приложение, которое объединит личные и рабочие дела пользователя в одном месте, поможет не упускать сроки их выполнения и обеспечит удобное взаимодействие внутри команды.
 
Chaos Control собирает в одном месте личные дела и задачи команды, помогает не пропускать дедлайны и показывает ход работы с помощью канбан-доски и диаграммы Ганта. Пользователь регистрируется и добавляет свои задачи с указанием сроков выполнения. Если пользователь состоит в команде, он также видит задачи, назначенные ему коллегами или работодателем. Все задачи отображаются на канбан-доске, где их можно перемещать между статусами «К выполнению», «В работе» и «Готово», а также на диаграмме Ганта, которая показывает распределение задач во времени.
 
### Целевая аудитория
 
Школьники, студенты, работники различных компаний.
 
## Главные фишки
 
- 🤖 **ИИ-ассистент для распределения задач** — считывает PDF-файлы или фотографии (например, расписание или список дел) и самостоятельно распределяет задачи по неделе
- 📊 **ИИ-ассистент для анализа продуктивности** — анализирует историю завершённых и незавершённых задач
- 📅 **Удобный календарь** — работа с событиями как в Google Календаре
- 👥 **Командная работа на общем календаре** — совместное отслеживание дедлайнов
- 🗂 **Командная канбан-доска и диаграмма Ганта** — совместное управление проектами
## Ключевые экраны
 
| № | Экран | Описание |
|---|-------|----------|
| 1 | Список всех дел | Общий перечень задач пользователя |
| 2 | Календарь | Заполнение и просмотр событий по датам |
| 3 | Канбан-доска | Задачи по статусам: К выполнению / В работе / Готово |
| 4 | Диаграмма Ганта | Распределение задач во времени |
| 5 | История задач | Завершённые и незавершённые задачи |
